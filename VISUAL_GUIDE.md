## Carousel Behavior

When multiple results are returned (e.g., 4 recipes, 4 beaches, 4 events), they appear as a **scrollable carousel** in ChatGPT:

```
┌─────┐  ┌─────┐  ┌─────┐  ┌─────┐
│Card │  │Card │  │Card │  │Card │
│  1  │  │  2  │  │  3  │  │  4  │
└─────┘  └─────┘  └─────┘  └─────┘
   ◀                              ▶
```

Users can:
- **Scroll horizontally** to view all cards
- **Click action buttons** on any card
- **Compare options** side-by-side
- **See all details** without leaving the chat

---

## Interactive Features

### Action Buttons
All buttons are clickable and trigger immediate actions:
- **Book Tasting** → Opens booking form
- **Add to Cart** → Adds item to order
- **View Surf & Rip Risk** → Shows detailed safety info
- **Get Directions** → Opens map/navigation
- **Call Driver** → Initiates ride request
- **Book Tickets** → Opens ticket booking

### Status Indicators
Visual indicators provide quick information:
- 🟢 **Green** = Safe/Good conditions
- 🟡 **Yellow** = Moderate/Caution
- 🔴 **Red** = Dangerous/Avoid

### Rich Content
Each card includes:
- **Emoji headers** for quick identification
- **Formatted text** with bold and bullets
- **Contact information** (phone, location)
- **Pricing and timing** clearly displayed
- **Safety warnings** when relevant
